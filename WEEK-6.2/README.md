# Week 6.2 - Full Stack Application

Welcome to the **Week 6.2** project! This repository contains a complete full-stack application, demonstrating the integration between a Node.js/Express backend and a React frontend.

## 🚀 Overview

This project showcases how to structure and run a modern full-stack web application. It is divided into two main parts:
- **Backend**: A robust REST API built with Node.js and Express.
- **Frontend**: A dynamic user interface built with React.

## 🛠️ Technologies Used

### Backend
- **Node.js**: JavaScript runtime environment.
- **Express.js**: Fast, unopinionated, minimalist web framework for Node.js.

### Frontend
- **React**: For building the user interface.

## 📂 Project Structure

- **`backend/`**: Contains the Node/Express server code, API routes, and database configuration.
- **`frontend/`**: Contains the React application, UI components, and state management.

## ⚙️ Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- npm or yarn

## 📖 Setup Instructions

To get the application up and running, you'll need to start both the backend and frontend servers.

### Starting the Backend

1. **Navigate to the backend directory:**
   ```bash
   cd backend
   ```

2. **Install backend dependencies:**
   ```bash
   npm install
   ```

3. **Start the server:**
   ```bash
   npm start
   ```
   *(Note: You can also use `node index.js` or `node server.js` depending on the entry point).*

### Starting the Frontend

1. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

2. **Install frontend dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
