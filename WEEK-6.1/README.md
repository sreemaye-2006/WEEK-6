# Week 6.1 - Initial React Project

Welcome to the **Week 6.1** project! This repository contains the foundational setup for a React application, built with Vite. It serves as an entry point for understanding modern React development workflows.

## 🚀 Overview

This project is designed to help developers get started with React using Vite, a blazing fast build tool. It includes a basic project structure, ESLint for code quality, and standard React dependencies.

## 🛠️ Technologies Used

- **React 19**: A JavaScript library for building user interfaces.
- **Vite**: Next Generation Frontend Tooling for fast development.
- **ESLint**: For identifying and reporting on patterns found in ECMAScript/JavaScript code.

## ⚙️ Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- npm or yarn

## 📖 Setup Instructions

Follow these steps to run the application locally:

1. **Navigate to the project directory:**
   ```bash
   cd WEEK-6.1
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/`: Contains the source code of the React application.
- `public/`: Static assets that are served directly.
- `package.json`: Project metadata and dependencies.
- `vite.config.js`: Configuration file for Vite.
